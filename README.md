
# TeamLodgr

Group hotel booking for sports teams and events.

Search hundreds of hotels, find availability across multiple booking sites, and share one link with your team. Each member books their own room.

## Features
- Search hotels by city, dates, and rooms needed
- Real-time room availability from multiple providers
- Shareable link for your team
- Works on mobile

## Built With
- HTML/CSS/JavaScript
- Vercel (hosting + serverless functions)
- Booking.com API
- Hotelbeds API
